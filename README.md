# SnapTrans 截图翻译

Windows 上的截图 OCR 实时翻译工具，用法类似 macOS 上的 Bob，可以和 Snipaste 同时使用。

按快捷键 → 框选区域 → 立即识别文字 → 流式显示译文。

## 功能

启动后会打开**主窗口**（关闭时最小化到托盘，快捷键仍然可用）：

- 工具栏：📷 截图翻译 / 🔤 截图识字 / 📋 翻译剪贴板图片
- **截图记录**：每次截图都会保存图片、识别出的原文和译文，并显示耗时；支持搜索、预览、复制图片、另存为、重新识别、修改原文后重新翻译、删除（可多选，按 Delete 键）
- **设置**：快捷键（点击输入框后直接按组合键）、目标语言、OCR 引擎、翻译服务商 / API Key / 模型、记录保留条数、开机启动等

快捷键和其他入口：

- **截图**（默认 `` Ctrl+` ``）：类似 Snipaste。框选后截图界面不关闭，可以继续：
  - 拖动 / 拉边角调整选区，方向键微调；鼠标悬停会高亮窗口，单击直接选中整个窗口
  - 标注：矩形 `R`、椭圆 `E`、箭头 `A`、画笔 `P`、荧光笔 `M`、文字 `T`、马赛克 `X`，可选颜色和粗细，`Ctrl+Z` / `Ctrl+Y` 撤销 / 重做
  - `Enter` 或双击：复制到剪贴板；`Ctrl+P` 贴到屏幕；`Ctrl+T` 翻译；`Ctrl+O` 识字；`Ctrl+S` 保存；`Esc` / 右键：取消
- **贴图**：钉在屏幕最上层。拖动移动，滚轮缩放，`Ctrl+滚轮` 调透明度，**`,` / `.` 翻看上一张 / 下一张历史截图**，`Ctrl+T` 翻译（译文贴在贴图旁边，并跟着贴图移动），双击或 `Esc` 关闭，右键查看更多操作
- **截图翻译**（默认 `Ctrl+1`）：框选后识别并翻译，**译文以气泡形式贴在选区旁边**，不遮挡原文。点「展开」才会打开完整窗口（可以修改原文、切换语言）。也可以在设置里改成始终弹出窗口
- **截图识字**（默认 `Ctrl+2`）：只识别文字，并复制到剪贴板
- **翻译剪贴板图片**：从托盘菜单打开，例如用 Snipaste 截图后直接翻译
- 支持多显示器和高 DPI；在选区内右键或按 `Esc` 取消
- 结果浮窗：原文可以修改，`Ctrl+Enter` 重新翻译，`Ctrl+Shift+C` 复制译文，可以临时切换目标语言，📌 固定窗口
- 中英自动互译：原文已经是目标语言（比如中文）时，自动译成另一种语言（默认英文）

## 为什么快

| 环节 | 做法 | 典型耗时 |
| --- | --- | --- |
| OCR | Windows 系统自带 OCR，离线运行，按文字行高自动放大并补边距来提高准确率 | 50–150 ms |
| 网络 | 复用长连接；按下快捷键时就开始预热 TLS 连接，框选的同时握手已经完成 | 省掉约 200–500 ms |
| 翻译 | 流式输出，首字到达就显示 | DeepSeek 首字约 0.5–1 s |

## 服务商

翻译和在线 OCR 都使用 **OpenAI 兼容接口**，在设置里选一个预设，再填 API Key 就能用：

- 翻译：DeepSeek（默认）、硅基流动、通义千问、OpenAI、Ollama 本地，也可以自定义
- 在线 OCR（可选）：硅基流动 · DeepSeek-OCR、通义 qwen-vl-ocr、OpenAI，也可以自定义

> DeepSeek-OCR 是开源模型，DeepSeek 官方 API 没有提供它。可以通过硅基流动等平台调用，
> 也可以用 vLLM 自己部署后填写本地地址。在线 OCR 要上传图片，速度比本地 OCR 慢，
> 适合排版复杂的图片，日常翻译建议用 Windows OCR。

## 安装和运行

### 直接使用 exe（推荐）

把 `SnapTrans-win64.zip` 解压到任意文件夹，双击 `SnapTrans.exe` 即可，不需要安装 Python。
在设置里勾选「开机启动」后，会自动登记 exe 的路径。

自己打包：双击 `build.bat`。它会在独立的 `.venv-build` 中安装依赖并调用 PyInstaller，
输出 `dist\SnapTrans\SnapTrans.exe` 和 `dist\SnapTrans-win64.zip`。
打包时使用文件夹模式（onedir）：启动快，不需要每次把文件解压到临时目录。

### 从源码运行

需要 Windows 10/11 和 Python 3.10 以上版本。

```bat
setup.bat      :: 创建 .venv 并安装依赖（只需运行一次）
start.bat      :: 启动，程序常驻在系统托盘
```

首次启动会自动打开设置页，填好翻译 API Key 后点「保存设置」就可以用了。配置默认保存在 `%APPDATA%\SnapTrans\config.json`，截图记录以无损 WebP 压缩保存在本地 SQLite 数据库 `%APPDATA%\SnapTrans\history.db` 中（体积约为 PNG 的 1/3，且不会把用户本机的历史记录打包进 `dist\SnapTrans-win64.zip`）。如果在程序目录（`SnapTrans.exe` 所在目录）下新建 `data` 文件夹，则开启**便携模式**，配置与数据库都会保存在 `data` 文件夹内。程序已经在运行时再次启动，会直接把已有的主窗口调到前面；开机自启时只在托盘运行，不弹出主窗口。

### OCR 语言包

Windows OCR 依赖系统语言包。中文语言包可以同时识别中英文；如果经常翻译韩文、日文、英文等，可在程序「设置 → OCR」中点击 **「安装 OCR 语言包…」** 一键安装，或在 Windows「设置 → 时间和语言 → 语言和区域」中添加对应语言。装好后，在「识别语言」保持「自动」时，程序会并行调用已安装的所有语言引擎并自动择优挑选最准确的结果。

## 项目结构

```
snaptrans/
  app.py              托盘、快捷键、整体流程
  capture.py          截图遮罩：框选、窗口识别、标注工具栏
  annotate.py         标注图形绘制（矩形/箭头/马赛克等）
  clipboard.py        Win32 剪贴板立即写入与防覆盖序号保护
  winutil.py          枚举窗口 / 显示器（Win32）
  pin.py              贴图窗口
  bubble.py           译文气泡
  ocr.py              Windows 多语言并行 OCR / 在线视觉模型 OCR
  net.py              HTTP 长连接、预热、流式请求
  translator.py       翻译提示词、目标语言判断
  worker.py           后台线程任务
  history.py          截图记录（SQLite history.db + 无损 WebP 压缩）
  main_window.py      主窗口（工具栏、截图记录、设置）
  result_window.py    结果浮窗
  settings_panel.py   设置面板
  hotkey.py           全局快捷键（RegisterHotKey）
```
